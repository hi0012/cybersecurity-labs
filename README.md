# Cybersecurity Hands-On Labs

Write-ups from the hands-on labs I completed in **Principles of Cyber Security** at Wayne State University (Winter 2025). The labs ran in virtual environments with Windows Server/Active Directory, Linux, pfSense and Kali-style tooling. Each write-up covers what I did, the tools I used and what I took away from it.

| # | Lab | Tools | Domain |
|---|---|---|---|
| 1 | [Vulnerability Assessment & Pen-Test Report](labs/01-vulnerability-assessment.md) | Nmap, Zenmap, Nessus, OpenVAS | Vulnerability management |
| 2 | [Packet Capture & Traffic Analysis](labs/02-packet-capture-traffic-analysis.md) | Wireshark, SSH/SFTP, WLAN | Network security |
| 3 | [Authentication & Access Controls](labs/03-authentication-access-controls.md) | Active Directory, NTFS, SMB | Identity & access management |
| 4 | [Encryption for Confidentiality & Integrity](labs/04-encryption-confidentiality-integrity.md) | GPG, Kleopatra | Cryptography |
| 5 | [Implementing an IT Security Policy](labs/05-it-security-policy.md) | Group Policy, Defender, MS Baselines | Governance & policy |
| 6 | [Security Monitoring & Logging](labs/06-security-monitoring-logging.md) | Event Viewer, Snort, rsyslog, Tripwire | Detection & monitoring |

## Skills shown
Network scanning and enumeration · vulnerability scanning and CVSS-based prioritization · writing pen-test reports · packet analysis · Active Directory users, groups and ACLs · least privilege · PKI and GPG · Group Policy hardening · security baselines · IDS alerting · log analysis · file integrity monitoring · security policy writing
