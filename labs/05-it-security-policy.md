# Lab: Implementing an IT Security Policy (Group Policy)

**Tools:** Windows Server Group Policy Management, Microsoft Defender, Microsoft Security Baselines

## What I did
- Set a **domain password policy** through Group Policy and confirmed it was enforced by changing a user's password.
- Pushed a **Defender real-time protection policy** to domain machines and confirmed users couldn't turn it off (the settings showed as grayed out).
- Applied a **Microsoft Windows security baseline** and reviewed its recommended password and account lockout settings.
- Set up a **mobile device security policy**.
- Researched and wrote up the key parts of an **Acceptable Use Policy**: purpose and scope, authorized vs. prohibited use, data protection, and enforcement.
- Researched and wrote up the key parts of a **Privacy Policy**: what data is collected, why it's processed, user rights, third-party sharing, and security measures. I connected these to GDPR principles.

## Takeaway
A written policy only matters if it's enforced. Group Policy turns it into settings users can't bypass.
